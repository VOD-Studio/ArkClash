# 界面约束（ArkUI）

## 动效

- 状态反馈（按下、选中、展开、切换）只改颜色、透明度和描边。
- 只有交互本身就是"缩放"时才用缩放，比如图片预览。
- 面板、卡片、弹层默认直接出现或淡入淡出。只有需要表达明确的空间来源或去向时，才用方向性位移（比如从节点列表进入节点详情的转场）。
- 系统开启"减弱动态"时，所有非必要动效都停掉。

## 视觉

- 功能性圆角最大 16vp；胶囊形（圆角 = 高度的一半）是一种形态，不算超限。
- 浮起感只用一种轻软阴影（偏移 4vp、模糊 24vp、5% 不透明度）；分隔用 1px 描边。
- 颜色从资源文件（`resources/base/element/color.json` 和 `dark/`）引用，深浅色都要能用。

## 性能

UI 是"打开快、不耗电"这两个指标的主要承担者（见 AGENTS.md「产品底线」）。

- 首帧只依赖本地缓存（preferences、上次的快照），网络和内核数据在首帧之后到达。
- 长列表（代理组、节点、连接、日志、规则）用 `LazyForEach` 加 `@Reusable` 组件，按需渲染。
- 高频数据（流量速率、连接数）合并后再刷新，最多每秒刷新一次界面；页面进入后台就退订内核推送。
- 状态尽量拆细，只让真正变化的组件重绘。`build()` 里只描述界面，计算放在状态更新的地方。
