# 0023 配置覆写脚本在 VPN 进程执行

- 状态：已采纳，待真机验收

## 背景

FlClash v0.9.3 的脚本管理与配置覆写分别负责编辑和单选绑定。脚本接收含默认值的完整配置对象，返回的对象用于构建运行配置。一个脚本可以被多份配置引用。

## 决定

- `profiles/scripts.json` 原子保存有序脚本、修订和绑定。UI 与 VPN 扩展复用配置存储的短提交锁。网络任务先独立下载，提交时核对来源修订。删除脚本保留已有绑定，覆写页明确提示用户解除或重选。
- 使用 FlClash 固定版本的 `rquickjs-sys 0.12.2` 所包含的 MIT QuickJS-NG 源码。构建校验归档 SHA-256 并隐藏嵌入的 QuickJS 符号，手机和宿主使用同一实现。每次执行使用新运行时，限制为 10 秒、256 MiB 堆和 512 KiB JS 调用栈。Promise 由运行时排空微任务。控制器只返回错误阶段和行列，`console` 方法接收调用并丢弃参数。运行时链接标准 JavaScript 内建，省略 QuickJS 的系统与 I/O 适配库。
- 标准和脚本模式互斥。脚本从原始配置构建，处理后仍应用 ArkClash 持有的网络与控制面设置。控制器凭 boot ID、配置版本和脚本修订应用新脚本。编辑时将脚本变换放在内核提交锁之外，转发继续使用最后成功的运行版本。启动或普通配置刷新使用当前已保存的绑定。
- JavaScript 编辑器使用随 HAP 安装的 CodeMirror，页面可编辑的字符串只作为文档内容传入。ArkWeb 禁用联网和沙箱文件访问，通过受限状态回调驱动原生保存和退出操作。远程脚本复用订阅下载和资源调度，应用前台与 VPN 服务沿用现有网络路由。

## 后果

自动同步会覆盖远程脚本的本地编辑。选择或保存脚本可以产生待应用修订，失败时保留编辑和最后成功的运行状态。脚本源正文上限 4 MiB，单个脚本库上限 16 MiB，配置 JSON 单向上限 64 MiB。脚本引擎与内核仍在同一 VPN 进程，因此引擎崩溃会影响 VPN。

性能验收在同一真机、同一配置和网络条件下分别记录无脚本和启用脚本的冷启动至可操作、8 小时待机耗电、新连接时延和 24 小时 boot ID。脚本生效需要记录热切换耗时，并在保持旧转发的情况下验证执行失败。宿主限额测试与模拟器原生加载结果单独报告。

本轮宿主以空配置重复创建、执行并释放 100 个 QuickJS 运行时，耗时约 13.3 ms。ARM64 调试 HAP 为 84.93 MB，内核为 64.72 MB。模拟器已验证脚本保存重开、文件和 URL 导入、远程同步与拖动排序。模拟器显示无法确认代理宿主状态，配置绑定的端到端应用和转发需真机复验。
