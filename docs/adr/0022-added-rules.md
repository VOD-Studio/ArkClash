# 0022 全局附加规则优先于配置规则

- 状态：由 [0028](0028-standard-profile-overrides.md) 扩展

## 背景

全局附加规则需要跨配置切换和订阅刷新保留。ArkClash 的订阅和本地配置共用同一套配置应用流程。

## 决定

- 将有序规则保存到 `added-rules.json`。内核在 `applyOverrides` 中把它们按列表顺序放到原配置规则前面。`MATCH-TARGET` 继承原配置最后一个 `MATCH` 的策略。原配置未写 `MATCH` 时使用 mihomo 规则模式的默认直连策略。
- 规则使用跨配置可用的策略和匹配类型。HarmonyOS 继续关闭进程查找，附加规则编辑器因此省略进程与 UID 字段，BT 预设使用 GeoSite Tracker 类目。
- 复用 DNS 覆写的版本校验、文件提交和在线热应用。通过认证控制器提交时用 mihomo 校验候选配置，复用已有 TUN。停止时只保存已通过界面校验的规则，加载具体配置时由内核完整校验。

## 后果

在线保存沿用配置热切换的转发暂停窗口。界面在打开时读取规则，并按需渲染可见行。规则按 mihomo 的规则模式参与匹配。

真机验收使用同一设备、配置和网络，记录冷启动到可操作、8 小时待机耗电、新连接建立延迟及 24 小时内核重启数。另记录在线变更的应用耗时，验证排序、切换配置后 `MATCH-TARGET` 重新解析及通过 `make log` 验证代理节点命中。宿主回归覆盖顺序、配置切换、冲突、无效规则与 TUN 复用，尚无本轮真机测量值。
