# 0029 常规设置、外部控制器与日志采集

- 状态：已采纳

## 决定

常规设置通过认证的 `/arkclash/general/settings` 在线提交。核心确认停止时由 UI 短锁提交到 `general-settings.json`。端口与认证字段缺失时沿用配置，五端口表单默认 mixed 7890、其余为 0。选节点时由内核读取保存的清理设置，旧数据沿用 UI 已保存的偏好。测速请求开始时锁定超时，订阅下载器在每次请求开始时读取 UA。Hosts 由 `applyOverrides` 逐域名合并，重建配置时保留平台 TUN。端口修改只重绑变化的标准监听器，待机只保存目标端口。

用户可选的外部控制器在 `127.0.0.1:9090` 独立监听并使用独立密钥。它只开放版本、状态、流量、连接、规则和代理的面板接口。节点写操作走 ArkClash 节点选择事务。接口返回的配置摘要只包含运行模式、端口、局域网开关和日志等级。停止或更换密钥时退休该监听器以及它接受的 WebSocket。内核日志等级与控制器调试路由解耦。

日志页复用诊断 WebSocket 的代次与背压协议。`/arkclash/diagnostics/logs` 只在捕获打开且页面订阅时注册 mihomo 日志观察器。Go 用非阻塞有界队列接收事件，最近 5000 项留在内存。切换配置、关闭捕获或最后一个订阅者离开时释放采集。日志只保留事件类别和脱敏内容，导出由用户选择目标并写当前未过滤快照。

日志记录的可选字段 `event` 和 `reason` 用于界面本地化。常见连接和 DNS 事件按模板归类。其余 mihomo 日志只使用构建时从日志调用点提取的字面量，预先去掉格式参数和 URL；动态正文统一归为未分类事件。详情、复制和导出使用同一份脱敏记录。

## 验收

宿主覆盖在线保存、端口冲突与 TUN 保留、HTTP 入站认证、外部控制器隔离、日志等级和退订。模拟器用于验证界面、沙箱保存、登录凭据和实际监听；ARM64 真机用于复验转发及冷启动、待机耗电、连接延迟和连续运行指标。
