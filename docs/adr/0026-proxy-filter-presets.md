# 0026 筛选预设与配置 YAML

- 状态：已采纳，待真机验收

## 背景

FlClash v0.9.3 的筛选库提供可复用的命名正则。代理组和代理集合将选中的正则复制到 `filter` 或 `exclude-filter`。默认预设来自同版本的 [FlClash 筛选定义](https://github.com/chen08209/FlClash/blob/v0.9.3/lib/models/config.dart#L35-L81)。

## 决定

- UI 在 `profiles/proxy-filters.json` 保存顺序和修订，沿用配置文件锁和原子提交。首次打开时使用 11 个内置预设，清空后保存空列表。新增或修改表达式时由 VPN 进程经认证 controller 使用 mihomo 的 `regexp2` 逐段编译。
- 配置内容编辑器将选用的表达式按反引号分段去重，再追加到选中对象的 YAML。改名、删除或修改预设不会改写以前保存的配置。配置继续走现有的草稿、修订检查和热切换流程。
- 在 TaskPool 中解析和编辑 YAML。常规字段按节点位置局部替换或插入。共享锚点由 YAML 编辑器显式处理，选择器不会修改共享值。

## 后果

- 只有打开筛选库、提交表达式或使用配置编辑器插入筛选才执行新增操作。内核启动和转发继续读取既有 YAML 字段。
- 真机验收需在连接中插入包含和排除预设，保存后检查代理组成员，再访问应匹配的站点并在 `make log` 核对选中的节点。当前没有 HDC 设备，尚无真机转发或性能数据。
