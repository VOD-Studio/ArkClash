# 0021 全局 DNS 逐项覆写

- 状态：已采纳，待真机验收

## 背景

订阅刷新会替换整个 YAML。用户选中的全局 DNS 设置需要跨订阅刷新和配置切换保留，且未选中的字段继续继承各自的配置。

## 决定

- 通过沙箱内的 `dns-overrides.json` 保存选中的字段及其版本。布尔值 `false` 和可选字段的空列表都是有效覆写。移除字段恢复继承。由 `applyOverrides` 合并，并保留 ArkClash 强制启用内核 DNS 的约束。
- 上游策略按域名项存储有序列表，每项可配置多个上游。空策略清除该配置的同名策略。Fallback 筛选按子字段继承与覆写，数字零表示显式选择的值。在线启用「遵循分流规则」或节点上游策略时，校验候选配置是否有节点解析上游。 [mihomo DNS 配置](https://wiki.metacubex.one/en/config/dns/)
- 确认内核停止时，界面在已有文件锁中校验版本并原子写入。内核运行时，通过认证控制器提交，校验启动实例与设置版本，再由 Go 解析候选并保存。核心交接期间的请求返回冲突或等待用户重试。
- 在线应用复用现有配置热切换、节点选择恢复和转发入口交接，保留当前 VPN 和 TUN。全局设置随下一次配置解析继续生效。监听地址变化时先检查 TCP 和 UDP 端口，解析或预检失败保留旧配置与落盘设置。

## 后果

配置页仅在打开时异步读盘，不订阅诊断流。在线保存当前配置会重建解析器，并沿用配置热切换的转发暂停窗口。离线先校验输入格式，内核在下一次加载具体配置时校验依赖。

真机验收使用同一设备、配置和网络，对照旧版本记录冷启动到可操作、8 小时待机耗电、新连接建立延迟及 24 小时内核重启数。另记录在线变更到保存反馈的时长，并通过浏览器和 `make log` 确认变更后的 DNS 查询和代理命中。宿主回归覆盖逐项继承、监听冲突、在线提交和 TUN 复用，尚无本轮真机测量值。
