# 0027 图标集库与代理组图标

- 状态：已采纳，待真机验收

## 背景

FlClash v0.9.3 的图标集清单使用 JSON，包含名称和图标地址。ArkClash 的代理页和仪表盘已经显示配置中的 `icon`。 [FlClash 图标集](https://github.com/chen08209/FlClash/blob/v0.9.3/lib/views/config/icon_sets.dart)

## 决定

- 本地和远程清单使用相同的解析器。接受 HTTP(S) 图标地址，按 URL 去重。清单上限为 4 MiB。打开预览时按可见网格项使用原生图片组件渲染。
- VPN 转发已就绪时，远程清单复用认证控制器和内核下载器。其他可确认状态下通过直接下载器导入。文件和远程下载均使用候选文件。解析成功及目录修订核对后原子提交，失败继续使用之前保存的清单。
- 选择器按代理组名称推荐图标，也可以搜索图标集或输入单张图标的 URL。选中的地址在后台写入配置草稿的 `icon` 字段，配置保存和应用沿用现有流程。

## 后果

更新或删除图标集只修改库，已选择的图标地址保存在各自的配置里。导入、预览和同步都由页面操作发起。真机需验证远程及文件导入、可见网格图片渲染、配置生效后代理页和仪表盘的图标显示，以及在线同步期间代理转发。当前没有 HDC 设备，尚无真机验收数据。
