# 0024 自定义代理库与内核校验

- 状态：已采纳，待真机验收

## 背景

FlClash v0.9.3 在「进阶配置 → 自定义资源 → 代理」维护本地节点。每个节点保存稳定 ID、原始 mihomo 定义和未填写的选项。分享链接只表示部分字段，部分协议也没有分享格式。

## 决定

- UI 在 `profiles/local-proxies.json` 保存节点、顺序和修订。沿用配置文件锁、原子替换和修订检查。列表重排和批量快编各提交一次，旧编辑遇到冲突时保留草稿。
- VPN 进程使用认证过的 `/arkclash/local-proxies/{operation}` 提供分享链接编解码及适配器参数校验。校验不连接节点，Tailscale 和 EasyTier 的试建适配器使用独立名称，避免覆盖运行中的 DNS 注册。共享链接和构造器原始错误可能包含凭据，接口只回传逐项结果和错误代码。
- 表单将显式添加的空选项留在 UI 元数据里。批量编辑原样保留未改链接对应的节点及不可编码节点。修改同名节点时，保留 ID 和原链接无法表达的字段。改名导致旧节点被移除时，先预览移除和新增项。
- 内核暂不可用时，手动表单可保存为待校验。库的用途是供自定义配置的代理组明确引用。自定义配置及代理组编辑由 [#84](https://github.com/VOD-Studio/ArkClash/issues/84) 跟进。

## 验证

保存节点和编解码属于页面按需操作，无周期任务。真机验收需验证 VPN 已断开时的内核预热、有效与无效链接、含本地节点引用的配置应用和实际转发。按协议记录真机连接结果。
