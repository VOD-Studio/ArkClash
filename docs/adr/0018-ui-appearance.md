# 0018 — 应用外观只由 UI 进程管理

## 状态

已采纳。

## 背景

以 [FlClash v0.9.3 主题页](https://github.com/chen08209/FlClash/blob/be84736605527034689c95bf27828ff27d912c5e/lib/views/theme.dart) 为行为参考。鸿蒙没有 Flutter 的全局 `ThemeData`、Android 的动态取色插件或 Prism 的桌面侧栏。应用原有页签、手势避让、原生材质与系统减弱动态设置仍需保留。

## 决定

- `AppearanceState` 在 UI 进程中持有一份偏好快照。启动时以异步 preferences 读取外观，不等待网络或内核。保存成功才应用，不写订阅、运行时或 VPN 进程。自定义色编辑在 Sheet 内预览，确认且 Sheet 退场后提交。
- 显示模式走 `UIAbilityContext.setColorMode`，系统栏前景随有效深浅色更新。Swift/Flutter/Android 像素值不作为契约：以带对比度校验的 OKLab 配色实现鲜艳、染色、柔和、单色与分层纯黑。系统色来自鸿蒙强调色资源；错误、警告、成功、上传和服务标志保留独立语义。
- 固定与悬浮复用 HdsTabs；悬浮默认仍使用原有迷你栏和原生滑动。淡入仅改内容透明度，不重建页签。沉浸光感以鸿蒙材质表示关闭、标准、通透，效果受硬件和系统材质策略限制。
- 自定义字号交给应用字体缩放 API；启用过自定义后，跟随模式通过系统配置监听继续接收真实系统字号。字体选择使用系统字体描述符，正文通过 ArkUI 字体属性热更新，代码和颜色值保留等宽字体。系统控制的菜单、键盘和状态栏不改字族。

## 后果

- 主题更改无需重启，也不重启连接或 VPN；选中页签与配置保持不变。
- FlClash 在 macOS/Windows 专用的侧栏背景模糊没有鸿蒙对应页面，不展示无作用的开关。
- 默认保留 ArkClash 的悬浮、滑动和沉浸材质，默认主题色采用 FlClash 的蓝色。纯黑只影响深色模式。
