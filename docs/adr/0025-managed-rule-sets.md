# 0025 规则集库与附加规则引用

- 状态：已采纳，待真机验收

## 背景

FlClash v0.9.3 支持维护独立的规则集。ArkClash 已有全局有序附加规则和规则匹配事务，可通过 `RULE-SET` 引用规则集库。

## 决定

- UI 读取本地目录和预览，用户编辑及本地导入先写入沙箱候选文件。VPN 进程经认证 controller 接受目录修订、内核代次和候选文件 ID，负责规则校验、下载及提交。
- 保留每个规则集的源文件，并生成从同一份内容校验得到的 Text 文件供 mihomo 读取。目录原子发布文件版本。编辑和同步先准备完整的新版本，有效更新才替换目录。下载复用当前内核出站，设置 20 秒请求上限。规则集库由用户发起同步。
- 附加规则以稳定 ID 引用规则集，改名保留引用。只有明确引用的资源进入运行配置，并使用独立的内核 provider 名。删前核对当前附加规则；更新活动资源复用现有规则热应用事务。脚本模式按原有顺序使用脚本输出。

## 后果

- 有效规则集支持 Domain、IPCIDR、Classical，以及 YAML、Text 和适用的 MRS。为限制解压和预览开销，源文件上限为 8 MiB，预览和行内编辑上限为 256 KiB。目录重排、改名和未引用规则集的保存只提交目录。
- 真机验收需要从页面新建、导入、预览和同步，再设一条 `RULE-SET`，在 VPN 连接期间访问规则集匹配的网站并以 `make log` 核对命中的代理节点。故意切到无效来源后，验收原规则仍生效。
- 性能验收在同一台真机上分别使用改动前版本、改动后无引用版本和改动后引用规则集的版本。记录冷启动到可操作的时长、8 小时待机耗电、新连接建立时间和 24 小时内核重启次数。当前没有 HDC 设备，暂无真机数字。
