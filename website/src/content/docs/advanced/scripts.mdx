订阅与普通本地配置可绑定 JavaScript 脚本。加载配置时，VPN 进程用 QuickJS 执行脚本，再校验输出的 mihomo 配置。

## 使用步骤

<Steps>

1. 打开「工具 → 进阶配置 → 脚本」，点击新建或从本地文件导入 `.js` 脚本。
2. 定义 `main(config)` 函数并保存。
3. 前往「配置」页，在目标配置卡片点击「更多 → 覆写」，选中刚刚创建的脚本。
4. 如果这份配置正在运行，点「立即应用」，或退出覆写页以应用已保存的修改。其他配置会在加载时使用该脚本。脚本报错或结果校验失败时，会提示错误并保留原运行配置。

</Steps>

## 函数约定

- 入口函数必须命名为 `main(config)`。
- 参数 `config` 是已解析后的完整配置 JavaScript 对象。
- 函数必须返回修改后的配置对象；返回后的对象仍会继续经过附加规则、全局 DNS 与平台强制项覆写。

## 实用范例

### 在原有规则之前添加分流规则

示例中的域名使用 `example.com`。写自己的规则时，出口可使用 `DIRECT`，或填写配置中已有的节点或代理组名称。

```js
function main(config) {
  const extraRules = [
    'DOMAIN-SUFFIX,example.com,DIRECT',
  ];

  config.rules = [...extraRules, ...(config.rules || [])];
  return config;
}
```

### 调整 URLTest 代理组的检测间隔

```js
function main(config) {
  if (!Array.isArray(config['proxy-groups'])) {
    return config;
  }

  for (const group of config['proxy-groups']) {
    if (group.type === 'url-test') {
      group.interval = 300;
      group.tolerance = 50;
    }
  }

  return config;
}
```

<Aside type="tip">
  如果只是增删单条分流规则或修改 DNS 上游，通常不需要写脚本：直接使用 [附加规则与自定义资源](../rules-and-resources/) 和 [网络与全局 DNS](../network-and-dns/) 会更直观且易维护。
</Aside>
