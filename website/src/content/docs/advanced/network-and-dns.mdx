## 全局 DNS 逐项覆写

在「工具 → 进阶配置 → DNS」点「添加覆写项」，按需选择要修改的参数：

- **上游策略**：自定义 `nameserver`、`fallback`、`default-nameserver` 与 `proxy-server-nameserver`。
- **Fallback 筛选**：控制 `geoip`、`geoip-code`、`ipcidr` 与 `domain` 过滤条件。
- **Fake-IP 与缓存**：精细调节增强模式、Fake-IP 过滤列表以及 DNS 缓存开关。
- **逐项恢复**：移除某一项覆写并保存后，该项重新使用配置中的值。

内核在线时，保存全局 DNS 设置会在同一 VPN 隧道上重新应用配置。

### 追加系统 DNS

「工具 → 常规 → 追加系统 DNS」默认关闭。开启后：

- 保留原有上游，并在 `dns.nameserver` 中补入 `system://`。
- Wi-Fi 和蜂窝网络切换后，内核在下次向上游发起查询时读取新的系统 DNS。已缓存的答案沿用原 TTL。[系统 DNS 的设计与验证状态](../../developer/adr/0034-harmonyos-system-dns/)

## VPN 网络设置与分应用绕过

打开「工具 → 进阶配置 → 网络」可调整 VPN 隧道参数：

- **TUN 协议栈**：默认使用 gVisor。
- **MTU**：默认 1500。仅 IPv4 时可设为 576–1500，开启 IPv6 时可设为 1280–1500。
- **路由与 DNS 劫持**：可设置包含路由、排除路由和绕过私有网段。「DNS 劫持」控制进入 TUN 的通用 TCP/UDP 53 端口请求，系统分配的 VPN DNS 仍由内核处理。
- **绕过 VPN 的应用**：每行填写一个应用包名，使该应用走系统网络。ArkClash 的包名会自动加入排除名单。

<Aside type="caution" title="需要断开重连生效">
  修改协议栈、IPv6、MTU、路由、DNS 劫持或绕过名单后，断开并重新连接以应用设置。
</Aside>

## 常规设置

在「工具 → 常规」可以配置全局运行参数：

| 设置项 | 说明 |
|---|---|
| 入站端口与认证 | 设置混合、HTTP 和 SOCKS 端口、入站认证，以及是否允许局域网访问 |
| 外部控制器 | 在 `127.0.0.1:9090` 开启面板接口，使用独立的密钥 |
| 订阅 User-Agent | 自定义拉取远程订阅时携带的 HTTP User-Agent |
| 全局 Hosts | 配置跨配置生效的静态域名解析映射 |
| 测速与切换行为 | 调整延迟测试超时时间、切换节点后是否自动关闭旧连接 |
| 日志与更新 | 设置内核日志级别和「自动检查应用更新」 |

在常规设置中，可用「添加覆写项」指定内核参数。未添加的项沿用配置值或内核默认值。
