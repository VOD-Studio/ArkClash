## 附加规则与命名出口

### 全局与配置级附加规则

- **全局附加规则**：在「工具 → 进阶配置 → 附加规则」管理，可供订阅与普通本地配置使用。结构化自定义配置在编辑器中管理自己的规则。
- **配置级附加规则**：在「配置 → 更多 → 覆写 → 配置附加规则」中为单份配置单独增补规则、指定最终 `MATCH` 目标，或临时停用某条全局规则。

### 命名出口

用命名出口可在不同配置中复用同一条附加规则：

1. 添加规则时，选择或新建命名出口，例如「流媒体」。
2. 在「配置 → 更多 → 覆写 → 命名出口」为该名称指定当前配置中的节点或代理组。

## 自定义资源库

打开「工具 → 进阶配置」，在「自定义资源」分组中选择相应入口。

### 1. 自定义代理库（「代理」）

- 维护本地自建或常用的节点库，支持按协议表单逐项填写，也支持批量粘贴/编辑分享链接。
- 内核就绪时使用 mihomo 校验节点定义。内核暂不可用时，手动填写的节点可暂存为待校验。
- 在「代理」页长按节点卡片，可将支持的节点存入本地代理库。

### 2. 托管规则集（「规则集」）

- 支持手动新建规则集，或从本地文件与远程 URL 导入 **YAML**、**Text** 与 **MRS** 格式规则集。
- 保存后，在「附加规则」中新增 `RULE-SET` 规则，选择对应规则集与出站策略即可生效。
- 远程规则集支持手动同步。内核按附加规则中的引用加载规则集。

### 3. 正则筛选预设（「筛选」）

- 将常用的地区或倍率过滤正则表达式保存为命名预设，保存前由 mihomo 同款正则引擎校验语法。
- 编辑配置内容时点「插入筛选」，选择代理组或代理集合，再选择「包含」或「排除」。表达式会插入草稿，完成后保存配置。

### 4. 图标集（「图标集」）

- 支持从本地 JSON 文件或远程 URL 导入图标集。VPN 已连接时，清单下载遵循当前分流规则。
- 编辑配置时点「选择图标」，可给代理组选择图标、填写图标 URL 或移除图标。保存并应用配置后，可在代理页和仪表盘查看效果。
