除了编写 JavaScript 脚本，ArkClash 提供一整套可视化的规则与自定义资源管理功能，所有数据均可在备份恢复时完整迁移。

## 附加规则与命名出口

### 全局与配置级附加规则

- **全局附加规则**：对所有配置生效，适合沉淀个人通用规则（例如内网直连、特定服务走指定出口）。
- **配置级附加规则**：在「配置 → 更多 → 覆写 → 配置附加规则」中为单份配置单独增补规则、指定最终 `MATCH` 目标，或临时停用某条全局规则。

### 命名出口

不同机场的代理组名称各不相同（有的叫 `节点选择`，有的叫 `Proxy`）。使用**命名出口**可以让同一套附加规则在多份订阅之间无缝复用：

1. 添加规则时，为该规则选择或新建一个抽象的**命名出口**（例如 `AI 服务`、`流媒体`）。
2. 在每份配置的「命名出口」页面，将该命名出口映射到本配置实际存在的节点或代理组即可。

## 自定义资源库

打开「工具 → 进阶配置 → 自定义资源」，可以集中维护以下四类资产：

### 1. 自定义代理库（「代理」）

- 维护本地自建或常用的节点库，支持按协议表单逐项填写，也支持批量粘贴/编辑分享链接。
- 分享链接的编解码与节点定义合法性均通过 VPN 进程内的 mihomo 核心直接校验，杜绝格式错误。
- 在代理页浏览订阅节点时，也可将看中的节点一键提取原始定义存入本地代理库。

### 2. 托管规则集（「规则集」）

- 支持手动新建规则集，或从本地文件与远程 URL 导入 **YAML**、**Text** 与 **MRS** 格式规则集。
- 保存后，在「附加规则」中新增 `RULE-SET` 规则，选择对应规则集与出站策略即可生效。
- 远程规则集支持手动同步；内核只会按需加载附加规则实际引用到的规则集，避免内存浪费。

### 3. 正则筛选预设（「筛选」）

- 将常用的地区或倍率过滤正则表达式保存为命名预设，保存前由 mihomo 同款正则引擎校验语法。
- 编辑配置内容时点击「插入筛选」，选择目标代理组或代理集合以及「包含（`filter`）」或「排除（`exclude-filter`）」，即可自动追加并保存。

### 4. 图标集（「图标集」）

- 支持从本地 JSON 文件或远程 URL 导入图标集清单（VPN 就绪时按当前代理规则下载清单）。
- 编辑配置文件时点「选择图标」，即可快速为代理组绑定图标、输入自定义图标 URL 或移除图标，立即在代理页与仪表盘生效。
