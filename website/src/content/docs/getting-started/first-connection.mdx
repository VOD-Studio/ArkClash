---
title: 首次连接
description: 授权系统 VPN、导入订阅或配置，并完成首次代理连接。
---

import { Steps, Aside } from '@astrojs/starlight/components';

<Steps>

1. **允许系统 VPN 授权**

   首次打开 ArkClash 时，应用会尝试预热内核。系统弹出 VPN 授权时，点「允许」。

   <Aside type="tip">
     授权后可以预先选择节点和做延迟测试。系统流量从点按连接按钮并建立 VPN 后开始接管。如果之前拒绝过授权，可以在「代理」页点「启动内核」重试。
   </Aside>

2. **导入订阅或配置**

   切换到「配置」页，点右上角的「＋」。选择「从链接导入」可粘贴订阅地址或节点分享链接。选择「文件」可导入本地 Clash / mihomo YAML，也可以扫码、从相册识码或新建自定义配置。

   导入完成后，点击该配置卡片将其设为**当前配置**。

3. **选择节点并连接**

   - 内核就绪后，可先到「代理」页选择节点，对单个节点或整组执行延迟测试。
   - 回到「仪表盘」，确认出站模式（规则、全局或直连），点状态卡片右侧的连接按钮。
   - 状态变为「运行中」后，VPN 按所选模式处理系统流量。

</Steps>

## 仪表盘信息速览

- 「状态」显示连接状态、运行时长和出口 IP。点出口信息可查看详情。
- 「配置」显示当前配置和代理组、节点、规则的数量。点卡片可打开详情。
- 「网络速度」显示实时上下行速率与累计流量。「连接统计」显示活跃连接、最近请求和 DNS 查询的计数。
- 「服务状态」显示前 4 项已启用服务的探测结果。打开卡片可查看其余已启用服务。
- 顶部的「运行状态」可查看内核状态、Geo 下载进度与应用更新。

## 断开与保持内核

在仪表盘断开连接会关闭系统 VPN 隧道。内核就绪期间可继续调整节点，并保留所选节点和延迟测试结果。
