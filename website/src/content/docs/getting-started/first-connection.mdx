title: 首次连接
description: 授权系统 VPN、导入订阅或配置，并完成首次代理连接。
---

import { Steps, Aside } from '@astrojs/starlight/components';

完成安装后，只需三步即可开始使用 ArkClash。

<Steps>

1. **允许系统 VPN 授权**

   首次打开 ArkClash 时，应用会尝试在后台预热独立核心并请求系统 VPN 授权。请在系统弹窗中点击**允许**。

   <Aside type="tip">
     允许 VPN 授权仅用于预热核心，**不会立即接管你的系统流量**。如果之前不小心点过拒绝，后续随时可以在「代理」页点击「启动内核」重新发起授权。
   </Aside>

2. **导入订阅或配置**

   切换到「配置」页，点击添加按钮，可通过以下任一方式导入：
   - **订阅链接**：粘贴远程订阅地址（支持 `age` 加密订阅）
   - **扫码 / 相册识别**：直接扫描订阅二维码或从相册选择
   - **本地 YAML / 分享链接**：导入本地 Clash / mihomo YAML，或将多条节点分享链接批量合成为一份配置
   - **新建自定义配置**：从空白或已有配置结构开始手动组装

   导入完成后，点击该配置卡片将其设为**当前配置**。

3. **选择节点并连接**

   - 核心就绪后，即使尚未开启 VPN，你也可以先切到「代理」页对分组或单个节点执行**延迟测试**，并选好心仪的节点。
   - 回到「仪表盘」，确认出站模式（规则 / 全局 / 直连），点击醒目的**连接**按钮。
   - 状态卡片变为运行中后，ArkClash 开始接管系统流量。

</Steps>

## 仪表盘信息速览

连接成功后，你可以在仪表盘一览关键运行事实：

- **状态卡片**：当前连接状态、运行耗时、出口 IP 归属与质量标签、启停按钮。
- **当前配置卡**：快速查看当前生效的配置名称、代理组数量、节点数量与规则数量；轻点可直接在首页打开详情抽屉，无需跳转页面。
- **出站模式**：使用原生沉浸光感分段控件在「规则」「全局」「直连」之间切换。
- **网络速率与服务状态**：实时上下行速率折线，以及前 4 项重点服务的连通性预览（展开抽屉可检测完整 13 项服务）。
- **顶部「运行状态」入口**：随时查看内核状态、Geo 下载进度与应用更新。

## 断开与保持内核

在仪表盘点击断开时，ArkClash 会关闭系统 VPN 隧道并停止接管流量，但会**保留已就绪的内核实例、节点选择和延迟测试结果**，方便你下次秒连或继续离线调整节点。
