## 主题与外观

打开「工具 → 主题」可实时预览所有外观调整，外观状态仅由 UI 进程管理，不影响 VPN 进程：

- **深浅模式**：支持跟随系统、浅色、深色以及面向 OLED 屏幕优化的**纯黑模式**（表面明度统一平移，保留层次而非一味死黑）。
- **OKLab 动态配色**：支持跟随系统强调色或自定义任意种子色，提供 **Vivid（鲜明）**、**Tinted（微染）**、**Soft（柔和）** 与 **Monochrome（单色）** 四种风格，所有前景与表面对比度均经过 WCAG 可读性校准。
- **材质与排版**：支持调节 API 26 沉浸光感材质等级、导航栏样式、页签动效、字体与全局字号。系统开启「减弱动态」时，应用自动停用非必要动效。

## 备份与恢复

打开「工具 → 备份与恢复」可将你的配置、规则与自定义资源安全迁移到其他设备或留档。

### 本地 ZIP 快照

- 一键导出包含当前配置、脚本、附加规则、自定义资源与设置的 ZIP 归档。
- 恢复时由独立于 VPN 内核的原生库 `libarkstore.so` 在后台执行解压校验与**原子目录交换**，避免恢复中途失败破坏现有数据。

### WebDAV 云端同步

- 支持绑定兼容 WebDAV 协议的网盘或自建存储服务，并手动触发上传快照与从远端恢复。
- 连接代理期间，WebDAV 请求支持遵循当前网络环境，便于访问海外或自建节点。

### 恢复范围与策略

执行恢复时，可按需组合以下选项：

| 维度 | 可选模式 | 说明 |
|---|---|---|
| 恢复范围 | **仅配置及资源** | 仅恢复订阅、本地配置、覆写脚本、附加规则及自定义资源 |
| 恢复范围 | **全部数据** | 在上述基础上连同应用设置、外观与网络配置一并恢复 |
| 冲突处理 | **合并** / **覆盖** | 选择与现有本地数据合并，或完全替换为快照内容 |

<Aside type="caution" title="妥善保管备份文件">
  导出的 ZIP 归档**未加密**，其中包含订阅链接、节点配置、age 私钥和 WebDAV 凭据等敏感数据。请勿将其上传至公开网盘或分享给他人。
</Aside>
