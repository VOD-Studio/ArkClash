## 主题与外观

打开「工具 → 主题」可实时预览外观调整：

- **显示模式**：可跟随系统或固定使用浅色、深色。深色背景可选「标准」或「纯黑」。
- **主题色**：可跟随系统强调色、自选颜色，并使用「鲜艳」「染色」「柔和」或「单色」配色。
- **材质与排版**：可调节沉浸光感、导航栏、页签动效、字体和字号。系统开启「减弱动态」后，应用会停用非必要动效。

## 备份与恢复

打开「工具 → 备份与恢复」，可将配置、规则和自定义资源迁移到其他设备，或保留一份快照。

### 本地 ZIP 快照

- 选择「仅配置及资源」或「全部数据」后导出 ZIP。选择「全部数据」会一并备份应用设置。
- 恢复时先校验归档，再呈现恢复方案。若数据已恢复但运行配置应用失败，可在页面重试应用。

### WebDAV 备份

- 支持绑定兼容 WebDAV 协议的网盘或自建存储服务，并手动触发上传快照与从远端恢复。
- 连接 VPN 时，WebDAV 请求按当前配置分流。断开 VPN 时使用直连。

### 恢复范围与策略

执行恢复时，可按需组合以下选项：

| 维度 | 可选模式 | 说明 |
|---|---|---|
| 恢复范围 | **仅配置及资源** | 仅恢复订阅、本地配置、覆写脚本、附加规则及自定义资源 |
| 恢复范围 | **全部数据** | 在上述基础上连同应用设置、外观与网络配置一并恢复 |
| 冲突处理 | **合并** / **覆盖** | 合并时保留备份中没有的本机项目。覆盖时会删除所选范围内备份中没有的本机项目，提交前需确认 |

<Aside type="caution" title="妥善保管备份文件">
  ZIP 归档未加密。配置数据可能含订阅链接、节点信息和 age 私钥，全部数据备份还可能含 WebDAV 凭据。请妥善保管。
</Aside>
