所有网络观测与资源维护入口均集中在「工具」页，设计上兼顾排查深度与低功耗。

## 连接与近期请求

打开「工具 → 连接」可以查看当前活跃连接以及近期已结束的请求：

- **后台不漏记**：只要内核就绪且应用存活，应用级采集通道就会在内存中持续记录最近 **2,000 条**请求；离开页面或退到后台不会丢失期间的记录，但列表仅在页面前台可见时才实时刷新，避免消耗电量。
- **多维筛选与分组**：点右上角「更多」可在弹出菜单中按协议、命中规则类型等维度连续多选筛选，并支持按域名/目标 IP 分组。
- **连接详情与关闭**：点按任意连接可查看基础信息、地址与完整代理链（点按整行即可复制），并支持手动关闭单个或全部活跃连接。

<Aside type="note">
  所有连接与 DNS 诊断历史仅驻留在内存中，**不落盘**，应用重启或内核完整重启后自动清空。
</Aside>

## DNS 查询

打开「工具 → DNS 查询」可实时观察域名解析、缓存命中与上游响应结果：

- 内存环保留最近 **3,000 条** DNS 查询记录，同样在应用存活期间持续采集。
- 支持暂停跟随，方便在高频请求下从容阅读单条记录。
- 支持一键**清理 DNS 缓存**：仅清理网络 DNS 缓存与传输状态，**保留**当前诊断历史与 Fake-IP 映射，不影响正在运行的连接。

## 日志捕获

打开「工具 → 日志」后可按需开启内核日志捕获：

- 日志流按内核代次隔离，内存中保留最近 **5,000 条**记录。
- 支持按级别筛选、关键词搜索、暂停滚动以及导出日志文本用于排障。

<Aside type="caution" title="分享日志前请脱敏">
  向社区反馈问题或提交 Issue 前，请先检查并打码订阅链接、节点地址与控制器密钥等隐私信息。
</Aside>

## Geo 数据资源管理

打开「工具 → 资源」管理 mihomo 使用的四类地理与分流数据库：

| 资源 | 说明 |
|---|---|
| `MMDB` | GeoIP 数据库（Country.mmdb / geoip.metadb） |
| `ASN` | 自治系统编号数据库 |
| `GEOIP` | GeoIP DAT 格式数据 |
| `GEOSITE` | 常见域名分类数据（geosite.dat） |

### 特性与行为

- **开箱内置**：HAP 安装包内置经过校验的 `geoip.metadb` 与 `geosite.dat`，首次装机无需翻墙下载即可按地区分流。
- **离线可管理**：未连接 VPN 时可查看各文件体积与更新时间、编辑自定义下载源地址；连接就绪后支持按项或全部下载更新。
- **自动更新**：默认开启，间隔 24 小时，开关与周期随应用升级保留；安装包升级不会覆盖你已接管更新的 Geo 数据。
- **原子热生效**：下载任务串行且可随时取消，离开资源页后仍在后台继续执行；校验通过后以原子指针切换 reader 与文件，**无需重建 TUN 或中断代理**。
- **恢复默认**：编辑下载地址时的「恢复默认」仅修改草稿，确认保存后生效，并在下一次更新时采用新源。
