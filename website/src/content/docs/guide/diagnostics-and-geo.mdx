## 连接与近期请求

打开「工具 → 连接」可以查看当前活跃连接以及近期已结束的请求：

- **采集与显示**：应用级采集通道保持连接时，离开页面或退到后台后仍会记录活动。内存保留最近 **2,000 条**请求，列表在前台可见时实时刷新。
- **多维筛选与分组**：点右上角「更多」可在弹出菜单中按协议、命中规则类型等维度连续多选筛选，并支持按域名/目标 IP 分组。
- **连接详情与关闭**：点按任意连接可查看基础信息、地址与完整代理链（点按整行即可复制），并支持手动关闭单个或全部活跃连接。

<Aside type="note">
  连接和 DNS 记录只保存在内存。切换运行配置或完整重启内核会清除旧记录。采集通道关闭期间的活动无法补录。
</Aside>

## DNS 查询

打开「工具 → DNS 查询」可实时观察域名解析、缓存命中与上游响应结果：

- 采集通道保持连接时，内存保留最近 **3,000 条** DNS 查询记录。
- 点「暂停跟随」可停在当前内容，查看单条记录。
- 「清理 DNS 缓存」清除网络 DNS 缓存与传输状态，保留诊断历史和 Fake-IP 映射。

## 日志捕获

打开「工具 → 日志」后可按需开启内核日志捕获：

- 捕获开启且日志页订阅期间，内存最多保留最近 **5,000 条**日志。离开日志页或关闭捕获后会停止采集。
- 支持按级别筛选、关键词搜索和暂停浏览。导出会保存当前捕获的完整快照。

<Aside type="caution" title="分享日志前请脱敏">
  向社区反馈问题或提交 Issue 前，请先检查并打码订阅链接、节点地址与控制器密钥等隐私信息。
</Aside>

## Geo 数据资源管理

打开「工具 → 资源」管理 mihomo 使用的四类地理与分流数据库：

| 资源 | 说明 |
|---|---|
| `MMDB` | GeoIP 数据库（Country.mmdb / geoip.metadb） |
| `ASN` | 自治系统编号数据库 |
| `GEOIP` | GeoIP DAT 格式数据 |
| `GEOSITE` | 常见域名分类数据（geosite.dat） |

- 安装包内置 `geoip.metadb` 和 `geosite.dat`。ASN 和 GEOIP 可在需要时下载。
- 未连接时可查看文件体积与更新时间，也可编辑下载地址。连接后可更新单项或全部资源。
- 自动更新默认开启，间隔 24 小时。已保存的设置和用户更新过的数据随应用升级保留。
- 离开资源页后，下载会继续。资源校验通过后在当前 VPN 中生效。编辑下载地址时，「恢复默认」只修改草稿，保存后从下次更新开始使用新地址。

## 运行中 Provider

在「工具 → 资源」向下滚动可查看当前运行配置的代理集合与规则集合。内核就绪后，可为支持本地替换的项目选择文件。连接 VPN 后，可手动更新远程 Provider。更新或替换失败时保留上一个有效版本。
