在 ArkClash 中，**订阅**指带更新间隔与用量信息的远程链接，下载后得到一份**配置**；从本机文件或分享链接导入的内容则是**本地配置**。所有配置统一在「配置」页管理。

## 多种导入方式

### 扫码与相册导入

在「配置」页可以直接调用相机扫描订阅或节点二维码，也可以从系统相册选取含二维码的图片。批量导入多条节点分享链接时，ArkClash 会自动将它们合成为一份完整配置。

### 网页一键唤起（URL Scheme）

支持在浏览器或第三方网页中通过以下协议唤起 ArkClash 的导入表单：

```text
clash://install-config?url=<经过 URL 编码的订阅地址>
```

除 `clash://` 之外，`clashmeta://` 与 `flclash://` 协议同样受支持。唤起后会先打开确认表单，用户确认保存后才开始下载。

要将自己的订阅分享给其他设备，可在订阅卡片的「更多 → 订阅二维码」中展示二维码。

### `age` 加密订阅

如果你的订阅内容使用 [age](https://age-encryption.org/) 加密：

1. 在单条订阅导入表单中填写对应的 **age 私钥**。
2. 后续无论是手动更新还是定时自动更新，都会自动使用已保存的私钥在本地解密。
3. 如需轮换密钥，可进入该配置的编辑页更换私钥。

<Aside type="note">
  订阅链接、节点信息与 age 私钥均仅保存在应用私有沙箱内，不会写入任何诊断日志。
</Aside>

## 自定义配置与 YAML 编辑

对于想完全掌控代理组与规则的用户，ArkClash 提供两种编辑形态：

- **结构化自定义配置**：在「添加 → 新建自定义配置」从空白组装，或通过「导入配置结构」解析已有 YAML。支持可视化编辑代理组、成员、拨号链（dialer-proxy）与规则，并可直接选用自定义代理库、筛选预设和图标集。
- **YAML 源码编辑与预览**：随时查看或编辑配置的 YAML 原文，也支持只读预览应用了脚本、附加规则、全局 DNS 与平台覆写之后的**运行时完整 YAML**，方便排查生效结果。

## 更新与热切换

- **订阅更新**：支持手动单条更新、批量更新与自动更新间隔；更新时同步记录机场返回的已用流量、总额度与到期时间（用量快照）。
- **无感热切换**：当**当前配置**更新成功或你切换到另一份配置时，只要内核在线，VPN 进程会直接重载配置并保持原有平台 TUN，**代理不中断、无需重新授权 VPN**。
- **安全回滚**：如果新配置解析或应用失败，ArkClash 会保留原运行配置继续工作，并通过原生轻提示报告真实错误原因。
- **后台预下载**：连接期间会在后台预先下载配置引用的 `rule-provider`，让下一次热切换无需等待远程规则下载。

## 每份配置独立记忆节点

ArkClash 关闭了 mihomo 全局混用的 `profile.store-selected`，改为按配置分别存储节点选择（`profiles/<id>.selected.json`）。切换到任意历史配置时，都会在启用转发前精准恢复该配置上次选定的节点，互不串扰。
