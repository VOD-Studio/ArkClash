订阅从远程链接获取配置，可设更新间隔，且可能带有服务商提供的用量信息。从本地文件或节点分享链接导入的内容会保存为本地配置。在「配置」页管理这些配置。

## 多种导入方式

### 扫码与相册导入

在「配置」页点「＋」，选择「扫码导入」用相机扫描订阅或节点二维码，或选择「从相册识码」。在「从链接导入」中批量导入多条节点分享链接时，ArkClash 会将它们合成一份配置。

### 网页一键唤起（URL Scheme）

支持在浏览器或第三方网页中通过以下协议唤起 ArkClash 的导入表单：

```text
clash://install-config?url=<经过 URL 编码的订阅地址>
```

除 `clash://` 之外，`clashmeta://` 与 `flclash://` 协议同样受支持。唤起后会先打开确认表单，用户确认保存后才开始下载。

要将自己的订阅分享给其他设备，可在订阅卡片的「更多 → 订阅二维码」中展示二维码。

### `age` 加密订阅

如果你的订阅内容使用 [age](https://age-encryption.org/) 加密：

1. 在「从链接导入」的单条订阅表单中填写对应的 **age 私钥**。解密需要内核就绪，可先到「代理」页点「启动内核」。
2. 后续无论是手动更新还是定时自动更新，都会自动使用已保存的私钥在本地解密。
3. 如需轮换密钥，可进入该配置的编辑页更换私钥。

<Aside type="note">
  订阅链接、节点信息与 age 私钥会保存在应用的私有数据中。导出的备份 ZIP 也可能包含这些信息，请妥善保管。
</Aside>

## 自定义配置与 YAML 编辑

- **结构化自定义配置**：在「添加 → 新建自定义配置」从空白组装，或通过「导入配置结构」解析已有 YAML。支持可视化编辑代理组、成员、拨号链（dialer-proxy）与规则，并可直接选用自定义代理库、筛选预设和图标集。
- **YAML 编辑与预览**：通过配置卡片的「更多」编辑 YAML，或打开「运行时配置」只读查看应用覆写后的 YAML。生成预览需要内核就绪，页面会标明当前预览是否已应用。

## 更新与热切换

- **订阅更新**：可手动更新一条或多条订阅，也可设置自动更新间隔。更新时记录服务商返回的已用流量、总额度与到期时间。
- **热切换**：内核在线时，更新当前配置或选中另一份配置会尝试热切换。切换沿用已建立的 VPN 隧道，部分旧连接可能需要重建。应用失败时，界面会提示错误，原运行配置会保留。
- **后台预下载**：连接期间，ArkClash 可预先下载配置引用的 `rule-provider`，缩短下一次热切换的等待时间。

## 每份配置独立记忆节点

每份配置单独保存节点选择。再次加载该配置时，内核在启用转发前恢复仍可用的选择。
